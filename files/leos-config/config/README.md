# Configuration historique LEOS

Ce dossier contient les valeurs de configuration initiales conservées pour compatibilité et référence. Les préférences réellement utilisées par les applications LEOS sont stockées dans le profil utilisateur via `leos_core/settings.py`.

Ce fichier est livré dans l'image sous `/usr/share/leos/config/desktop-defaults.json`. Il ne remplace pas les réglages KDE et n'est pas appliqué automatiquement au profil utilisateur.
