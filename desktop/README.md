# LEOS — Desktop Mode

Ce dossier accueillera les éléments spécifiques à l'expérience Desktop de LEOS.

Objectifs :
- personnalisation de KDE ;
- dock LEOS personnalisable ;
- thèmes et dispositions officielles ;
- fonds d'écran et widgets ;
- écran d'accueil, verrouillage et éléments visuels du bureau.

L'emblème officiel de ce mode est le lion seul.

Les outils Linux et KDE existants seront privilégiés lorsque cela est pertinent.

Aucun composant Desktop fonctionnel n'est encore intégré ici.
