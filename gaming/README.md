# LEOS — Gaming Mode

Ce dossier accueillera les éléments spécifiques à l'expérience Gaming de LEOS.

Objectifs :
- interface plein écran utilisable à la manette ;
- bibliothèque unifiée de jeux PC et émulés ;
- accès aux lanceurs et émulateurs compatibles ;
- tableau de bord et overlay de performances ;
- gestion des manettes et profils de configuration.

L'emblème officiel de ce mode est le lion avec la manette.

Les outils existants de Bazzite et de l'écosystème Linux seront réutilisés lorsque cela est pertinent.

Aucun composant Gaming fonctionnel n'est encore intégré ici.
